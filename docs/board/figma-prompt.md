# Prompt for a Figma board (copy everything below the line)

Create a Figma design file, **one large board (canvas ~1920 px wide)**, to present to a company Director. **All text on the board must be in Uzbek Cyrillic exactly as written below** (keep Latin only for: AI, API, SAP, KPI, OKR, RACI, Telegram, Instagram, WhatsApp, Verifix, Garmin, Londry, Outlook, 1C, Didox, B2B, IT, /commands).

**Style:** clean, corporate. Background #F6F5F1, cards #FCFBF8 with 1px #E1E0DA border, radius 16–20. Dark text #15171C, body #3D4250. Brand accent red #D71920. Status colors: done = green #1E6B35 on #E3F3E8, in progress = amber #8A5A00 on #FFF1D2, not started = grey #4F5463 on #ECEDF0 (always write the status word, not only color). Fonts: Rubik (headings), IBM Plex Sans (body) — both support Uzbek Cyrillic (ў қ ғ ҳ). Use auto-layout frames. Sections stacked top to bottom, each a separate frame with a title.

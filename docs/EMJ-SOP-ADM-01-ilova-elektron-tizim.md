**EMJIEM**

**EMJ-SOP-ADM-01 «Ёзма рухсат ва тасдиқ олиш тартиби» ҳужжатига илова № 1**

**Мавзу:** ёзма рухсатлар учун расмий электрон тизимни белгилаш

1. EMJ-SOP-ADM-01 тартибининг 3-бандига мувофиқ, ёзма сўров ва қарорлар учун
   расмий электрон тизим этиб **EMJIEM OPS Manager Telegram боти** ва унинг
   маълумотлар базаси белгилансин.

2. Тизим қуйидагиларни сақлайди ва ўзгартириб бўлмайди:
   - сўров рақами, қабул қилинган сана ва вақт;
   - сўров муаллифи, унинг лавозими ва Telegram ID си;
   - сўровнинг барча майдонлари (нимага рухсат сўралади, сабаб ва таклиф,
     сумма ва валюта, бажариш муддати, қарор керак бўлган вақт,
     шошилинчлик, иловалар);
   - тасдиқловчининг исми, лавозими, Telegram ID си, қарор санаси ва вақти;
   - қарор тури: тасдиқланди / шарт билан тасдиқланди / рад этилди /
     қўшимча маълумот керак;
   - қарор тарихи — ҳар бир ҳаракат вақти билан қўшиб борилади ва
     ўчирилмайди.

3. Ҳар бир қарордан сўнг тизим тўлдирилган ёзма шаклни (.docx) автоматик
   яратади ва сўров муаллифи ҳамда тасдиқловчига юборади.

4. Ўз сўровини ўзи тасдиқлаш тизим даражасида тақиқланади.

5. Қарор қабул қилиш ваколати: операцион директор ва директор ёзма равишда
   белгилаган ўринбосарлар. Ўринбосарлар рўйхати тизим созламаларида
   (`PERMISSION_DEPUTY_TELEGRAM_IDS`) сақланади ва фақат директор
   кўрсатмаси билан ўзгартирилади.

6. Шахсий чат, овозли хабар ва оғзаки келишув, аввалгидек, тасдиқ
   ҳисобланмайди.

7. Жавоб муддатлари (SOP 4-банд) кучида қолади ва ҳозирча қўлда назорат
   қилинади: тизим муддат бузилишини автоматик кузатмайди.
